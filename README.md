**Descrição:** Web App para Geomapeamento Interativo com visualização de dados espaciais.
**Contribuição Pessoal:** Atuei como desenvolvedor Frontend principal utilizando React.js. Integrei APIs de mapas (OpenLayers) para renderização de camadas de dados e desenvolvi filtros dinâmicos que permitem ao usuário manipular visualizações geográficas em tempo real.
**Tecnologias:** React, PostgreSQL, JavaScript.
**Repositório:** [Link para o repositório](https://github.com/candago-2/ABP-2-Semestre-Documentacao)

**Contribuição Pessoal:** Desenvolvi o dashboard do usuário utilizando React e TypeScript. Implementei formulários complexos com validação rigorosa de tipos e criei componentes reutilizáveis com Material UI, focando na performance e usabilidade mobile-first.
**Tecnologias:** React, TypeScript, MongoDB, Material UI.
**Repositório:** [Link para o repositório](https://github.com/RafaelSM21/abp_3_semestre_documentacao)

### 4DSM – 1º Sem. 2025 - Rastreamento Oceanográfico
**Descrição:** Plataforma de monitoramento de trajetórias marítimas em tempo real.
**Contribuição Pessoal:** Responsável pela interface de visualização de dados em tempo real. Implementei o consumo de APIs REST para exibir coordenadas geográficas e dados de sensores ambientais, garantindo a atualização dinâmica da UI conforme os dados eram recebidos do hardware (Arduino).
**Tecnologias:** React, PostgreSQL, Arduino IDE.
**Repositório:** [Link para o repositório](https://github.com/candago-4/documentacao)

### 5DSM – 2º Sem. 2025 - DogSpotter (Mobile)
**Descrição:** Aplicativo mobile para registro e rastreamento geolocalizado de animais.
**Contribuição Pessoal:** Desenvolvedor principal da aplicação mobile com React Native e Expo. Implementei a integração nativa com a câmera para captura de fotos, a API do Google Maps para rastreamento e gerenciei o estado global da aplicação com Context API.
**Tecnologias:** React Native, Expo, TypeScript.
**Repositório:** [Link para o repositório](https://github.com/candago-5/frontend)
